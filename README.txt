MANTRAWEST WEBSITE PACKAGE

Files:
- index.html: main website
- client-portal.html: Get Started page with Client Login and Create an Account routes
- style.css: main responsive styling and effects
- script.js: frontend interactions
- assets/: 20 visual pages rendered from the supplied Mantrawest/AOGL technical presentation

HOW TO PREVIEW
1. Keep index.html, client-portal.html, style.css, script.js and the assets folder together in the same website folder.
2. Open index.html in your browser, or use VS Code Live Server for the best local preview.
3. Click Get Started to open client-portal.html.

IMPORTANT
The login and registration buttons currently route to the existing Mantrawest website's login and registration paths. The rebranded static frontend does not itself implement authentication or connect to a database. Before replacing the live website, confirm that those existing routes and the database remain available, then connect the new frontend to the existing backend/API rather than creating a second database.

The assets are presentation-page visuals used as a temporary local image set. Replace any slide-style images with approved original project/site photographs when available.
